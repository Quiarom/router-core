# Blocked captures

No physical-router traffic is included yet. Capture only one local dashboard
session, sanitize it before saving, and replace credentials and session values
with `<ROUTER_ADMIN_PASSWORD>` and `<SESSION_TOKEN>`. Do not capture or commit
Wi-Fi secrets.

For each item below, preserve the complete HTTP request headers needed to
replay a read-only request (with cookies/tokens replaced) and the complete
HTML response body. The response must be from TL-WR841N/ND v8.4 stock
firmware, not a synthetic page.

## Login/authentication

* Dashboard/action: the login form at `http://192.168.0.1/`.
* Request to capture: the exact form submission request generated by the stock
  dashboard, including method, URL, field names, encoding, and cookie/token
  exchange, with the password replaced by `<ROUTER_ADMIN_PASSWORD>`.
* Response required: the complete login response and the first authenticated
  dashboard request/response, with all session values replaced by
  `<SESSION_TOKEN>`.
* Why blocked: firmware builds vary; router-core must not guess the login
  request shape.
* Sanitization: remove or replace passwords, cookies, authorization values,
  tokens, and personal client data before placing files in `fixtures/captured/`.
